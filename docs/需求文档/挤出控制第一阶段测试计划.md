# 挤出控制第一阶段测试计划

## 1. 记录字段

测试时保存原始发送行、MCU接收时间以及每秒输出的 `ESTAT`、`USTAT`。建议整理为：

```text
time_ms, seq, tool, E_mm, target_steps, submitted_steps, completed_steps,
ff_sps, v_sps, phase, state, dir, enabled, qdepth, fault, hard_fault
```

## 2. 软件检查

1. 执行 `idf.py build`，必须成功。
2. 执行 `git diff --check`，不得有空白错误。
3. 启动后确认只有统一 `extruder_rt` 任务控制M3/M4，旧M3/M4脉冲任务未启动。

## 3. 定量测试

按当前101.8591636 step/mm验证：

| 输入绝对E变化 | 期望累计步数变化 |
|---:|---:|
| 0.140000 mm | 14 step |
| 0.200000 mm | 20 step |
| 0.300000 mm | 31 step |
| 1.000000 mm | 102 step |

最终应满足 `completed_steps == target_steps`，且 `submitted_steps` 最终与两者一致。

## 4. 平顺性测试

连续发送至少10分钟：

```text
每4 ms增加0.001000 mm
```

通过条件：

- 运行中不出现持续正反方向交替。
- `abs(v_sps) <= 1800`。
- 队列深度在0到4之间。
- 相位始终在 `[0,1)`。
- 无RMT硬故障。
- 手触送料丝不应出现周期性反向冲击。

## 5. 加减速与反转

1. 从静止开始连续增加E，确认速度以不超过5000 step/s²升高。
2. 停止增加E，确认MCU自行减速并到达最终目标。
3. 发送合法回抽目标，确认先减速、队列排空、DIR_CHANGE后才反转。
4. 反转期间不得同时存在旧方向在途脉冲和新方向脉冲。

## 6. 丢包与溢出

- 人为丢弃一个中间E，后续绝对E到达后最终累计步数应恢复。
- 人为制造序号缺口，`USTAT seq_gap`应增加，电机不依赖上位机反馈继续受限规划。
- 制造软件队列满或UART溢出时，相应计数和fault位应增加。
- 丢弃最后一个E且不再发送，记录最终目标不可恢复，这是已接受边界。

## 7. 复位

- 有在途脉冲时发送extrude_reset，只有账本排空后才能EVDONE。
- 复位成功后target/submitted/completed均为0，EN关闭。
- 150 ms内无法结算时应返回reset_timeout并进入硬故障，不能假装建立新原点。

## 8. 热机与带载测试

在实际TMC2209驱动板、42电机、12 V、真实送料背压下完成：

1. 连续送料30至60分钟。
2. UART静默后保持EN至少30分钟。
3. 记录驱动板温度、电机外壳温度、12 V驱动板端电压和VREF/相电流。
4. 每5分钟以相同手动力反向拉料，观察是否出现周期性可拉动/不可拉动。
5. 分别测试StealthChop和SpreadCycle（若硬件可选）。

硬件通过条件应以电机和驱动板厂家额定值为准；不得把TMC2209的峰值电流当作小模块连续能力。
