# 上位机挤出发送优化建议（后续）

以下建议均为后续优化，不是第一阶段MCU执行的前置条件，也不要求修改机器人运动链路。

## 1. 保留E精度

- 使用double保存轨迹累计E。
- 序列化时固定输出至少6位小数。
- 去重应基于即将发送的字符串或定点整数，避免先按高精度判定变化、随后序列化成相同文本。

## 2. 最终目标保护

打印段结束、暂停或文件结束时，可重复发送最后一个绝对E两到三次，并保持相同目标。这样可降低“最终E永久丢失且无后续报文”风险。

## 3. 序号

- 建议每个4 ms采样周期递增uint32序号。
- 不要在同一会话中无提示地回退序号。
- 可在日志中同时保存轨迹帧号和实际UART发送序号。

MCU不会仅因旧序号拒收绝对E，序号主要用于估速和诊断。

## 4. 发送队列

- 采用有上限的单写线程队列，避免多个线程交错写UART。
- 队列积压时优先保留最新绝对E，而不是补发所有过期中间点。
- 记录入队、出队、串口写完成时间和丢弃计数。

## 5. 状态记录

建议联调工具记录E、EACK、ESTAT、USTAT并按MCU时间对齐。不要等待EACK才继续4 ms发送；EACK已限频到约20 Hz。

## 6. 可选增强

后续若允许改协议，可增加会话号、最终目标重复标志、CRC以及显式打印开始/结束事件。但这些增强不能恢复上位机序列化前已经丢失的E精度，也不能在没有送料编码器时检测物理失步或打滑。
