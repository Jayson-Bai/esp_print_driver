# 上位机挤出接口要求（第一阶段）

## 1. 边界

本文只规定上位机到挤出MCU的UART数据，不要求修改机器人运动、轨迹插补、KUKA控制或打印主流程。MCU负责本地基础运动规划，上位机不需要根据MCU状态回报来驱动、暂停或停止挤出。

## 2. 串口

```text
115200 baud, 8 data bits, no parity, 1 stop bit
```

每条命令必须以 `\n` 结束；可带 `\r\n`，MCU会忽略 `\r`。

## 3. 正式挤出命令

```text
E <seq> <tool_id> <absolute_E_mm>\n
```

示例：

```text
E 1001 1 12.345678
```

要求：

- 标称发送周期4 ms。
- E必须是当前打印会话中的累计绝对值，不是4 ms增量。
- 对正常G代码/切片轨迹，送料段E应单调增加；合法回抽允许减小。
- `tool_id`只能是1或2。
- `seq`使用uint32，可回绕；建议每个采样周期单调加1。
- 建议至少发送小数点后6位。上位机序列化前已经损失的精度无法由固件恢复。
- 不要把MCU返回的EACK当作逐包确认；EACK最多约20 Hz。

## 4. 复位

已有事件格式继续使用：

```text
EV <event_seq> extrude_reset <tool_id>\n
```

MCU等待在途RMT脉冲结算后才完成复位。可能返回：

```text
EVACK <event_seq> extrude_reset accepted <mcu_us>
EVDONE <event_seq> extrude_reset done <mcu_us>
EVERR <event_seq> extrude_reset reset_timeout <mcu_us>
```

当前上位机若始终使用 `event_seq=0`，MCU允许重复复位，不进行幂等去重。

## 5. 状态回报

- `STAT`：原有温度、风扇、工具和最近E状态。
- `ESTAT`：挤出规划和脉冲账本。
- `USTAT`：UART与软件队列异常计数。

第一阶段执行不依赖这些回报。上位机可以忽略，但联调时建议记录。

## 6. 丢包语义

中间E丢失时，后续绝对E可把目标推进到正确累计位置，MCU按速度和加速度限制追赶。永久丢失且没有后续报文的最终E无法恢复，上位机也不应假设MCU能够猜测缺失目标。

## 7. 上位机无需满足的事项

- 无需发送机器人速度或位姿给挤出MCU。
- 无需按ESTAT状态切换机器人运动阶段。
- 无需等待EACK才发送下一条E。
- 无需根据MCU的STOP/RESET状态自动停止机器人；此类联动不属于第一阶段。
